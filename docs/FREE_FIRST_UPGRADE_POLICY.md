# Free-First Upgrade Policy

AgentOS must be useful at the free/limited capability level. Paid subscriptions and API access are optional capability upgrades.

## Recommendation triggers

The Overseer may recommend a paid model, agent or automation service only when at least one of these is true:

- a material capability gap is detected;
- the current free/connected workers cannot meet a stated requirement;
- a temporary workload spike makes a one-month subscription materially beneficial;
- an existing connected provider is insufficient for the required autonomy, capacity or integration.

## Recommendation order

1. Use available free/limited workers.
2. Use an existing connected subscription/API.
3. Use an available fallback worker.
4. Recommend a paid subscription or API only when justified.
5. Prefer a short-term/one-month option when the need is temporary.

## Acquisition choices

A recommendation should distinguish:

- **Connect existing account** — when a supported integration is already available;
- **API access** — when programmatic access is the correct integration and the provider sells it separately;
- **Subscription** — when the consumer product supplies the required capability;
- **Official referral/affiliate route** — when a verified programme exists;
- **No purchase** — when existing capabilities are sufficient.

## Commercial safeguards

Affiliate/referral/reward information must be disclosed. Commercial relationships may help explain available acquisition paths but must never cause AgentOS to recommend a technically inferior provider.

## Example recommendation

> Your current workers can complete the task, so no new subscription is recommended.

or:

> This month's workload has a temporary automation requirement. n8n would materially reduce manual work. A one-month trial is recommended. You can connect an existing account or use the verified acquisition route.

## No artificial scarcity

AgentOS must not manufacture capability gaps, exaggerate benefits, conceal free alternatives, or pressure the user to purchase a subscription/API.
