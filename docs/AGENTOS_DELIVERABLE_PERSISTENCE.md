# AgentOS Deliverable Persistence

For future AgentOS task work, save final deliverables and relevant supporting files to this repository before reporting completion. Use a dated, descriptive path under `docs/` for final documents and `docs/research/` for raw research outputs, datasets, logs, and other supporting artifacts. Review the working tree, commit the files with a clear message, and report the commit and paths in the final response. Do not leave completed deliverables only in the temporary sandbox.
