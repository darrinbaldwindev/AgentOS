# AgentOS Next Architecture Decision

**Decision:** Adopt the governance, reliability and integration capabilities as first-class AgentOS architecture, subject to incremental proof and existing backlog priority.

## Accepted additions

- Policy Engine
- Mission Ledger
- Trust & Reputation
- Recovery / Resume Engine
- Provider-neutral Event Bus
- Simulation / Sandbox Mode
- AgentOS Constitution

## Non-duplication rule

These additions extend the existing dispatch, state, authority, verification, scheduler, workspace, Skill Agent, Green Agent and PRS contracts. They do not create a second runtime, router, scheduler, state store, or assurance platform.

## Commercial alignment

These capabilities strengthen the proposed Overseer (Powered by AgentOS) governance/control-plane product, particularly CI/CD governance, budget control, approval boundaries and auditable evidence. Commercial claims remain hypotheses until independently validated.

## Safety boundary

No production provider activation, credentials, billing activation, uncontrolled autonomy, or safety bypass is implied. Deterministic fixtures and dry-run/simulation evidence precede live activation.
