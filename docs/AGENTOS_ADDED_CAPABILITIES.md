# AgentOS Added Capabilities — 2026-09-01

The following capabilities have been accepted into the AgentOS architecture:

- Policy Engine
- Mission Ledger
- Trust & Reputation Layer
- Recovery / Resume Engine
- Event Bus
- Simulation / Sandbox Mode
- AgentOS Constitution

The architecture remains provider-neutral. Existing canonical dispatch/state/authority/verification components remain authoritative. PRS remains independent assurance, Green Agent remains read/analyse/report/challenge, and external automation remains non-authoritative.

Implementation is staged behind deterministic testing and existing P0 reconciliation.
