**Status:** MARKETING PRODUCTION BRIEF
**Use:** Content360, Meta, Instagram, TikTok, YouTube Shorts, LinkedIn, X, website.

## Visual system

Use one consistent AgentOS visual family:
- modern blue / violet / indigo SaaS palette
- clean white text on dark or gradient backgrounds
- laptop/dashboard UI as central product object
- Willow / Isla / Jack / Henry used functionally, not as childish mascots
- strong hierarchy, minimal text per frame
- large captions safe for mobile
- avoid fake metrics, fake reviews and unverified performance figures

## Claim gates

Do not visually imply a capability is live merely because it is shown as a concept. Use labels such as **Designed for**, **Coming capability**, **Concept**, or **Under test** where appropriate.

Do not show fabricated dashboards that appear to be current measured customer savings without labeling them as mockups.
